# AI Programming Assignment 5 – CS2201

This repository currently contains the codes and documentations for the following questions detailed in our Programming Assignment 5 for the CS-2201 course:

```
1. Implement the Minimax Search algorithm, Alpha-Beta Search, Heuristic Alpha-Beta Search, and Monte-Carlo Tree Search (MCTS). Demonstrate their working using a suitable game environment.
2. Design an AI-based Travel Planner that reuses existing domain knowledge bases such as tourist places, food recommendations, personalized tour plans, and cost assessment.
3. Describe Knowledge Graphs and explore the tools used to build Knowledge Graphs. Demonstrate the construction, representation, querying, and visualization of a Knowledge Graph.
4. Explore the tools for modelling, problem representation, and inferencing using Bayesian Networks. Choose a suitable example and implement it.
```

The codes and related documentation (if required) have been posted within the respective folders (named as per the question).

To clone this entire repository, please use:

```bash
git clone https://github.com/sushilingala-ai/SE24UCSE168_AI-ProgrammingAssignment5.git
```

---

## Repository Structure

The repository is organized into the following folders:

* **Q1-GameTreeSearch**
  Contains the implementation of Minimax Search, Alpha-Beta Search, Heuristic Alpha-Beta Search, and Monte-Carlo Tree Search (MCTS) using a Tic-Tac-Toe game environment.

* **Q2-AITravelPlanner**
  Contains the implementation of an AI-based Travel Planner that utilizes domain knowledge bases for destination recommendation, food recommendation, personalized tour planning, and cost assessment.

* **Q3-KnowledgeGraphs**
  Contains the implementation of a Knowledge Graph using NetworkX and RDFLib. The project demonstrates knowledge representation, graph construction, querying, visualization, and RDF/Turtle export.

* **Q4-BayesianNetworks**
  Contains the implementation of a Bayesian Network for medical diagnosis using the Chest Disease example. The project demonstrates Bayesian Network modelling, problem representation, inference using Variable Elimination and Belief Propagation, and visualization.
